# Security policy

Aster 0.1 is an experimental language implementation and has not been independently audited. Do not use it as the sole protection for untrusted code or safety-critical systems.

Until a public security contact and release process are established, please report suspected vulnerabilities by opening a private security advisory in the project's hosting environment rather than posting exploit details publicly. Maintainers should reproduce the issue, add a regression test, assess both VM and native-backend impact, and document affected versions before publishing a fix.
